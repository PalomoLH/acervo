🎲 Configurar admin

Acervo

Faça isso uma vez (ou quando o token expirar):

  1. No GitHub, crie um fine-grained token: Repository access → Only select repositories → acervo; Permissions → Contents: Read and write. Escolha a validade que quiser.
  2. Cole o token abaixo e defina a senha de admin.

O token é salvo criptografado com a senha em data/auth.json. Sem a senha ninguém consegue usá-lo. Ele nunca é enviado para outro lugar além da API do GitHub.
